screenshots, copied without modification. Each screenshot was visually checked
against its source paper and the relevant methods, results, and figure captions.
The shared `publicationFigures.js` mapping supplies both publications and projects.

The five published/manuscript PDFs were read from the author's existing
`AI-Energy/My_Research_Papers/` directory. For reverse vaccinology, both the linked
Research Square v1 PDF and the revised local manuscript were checked. The supplied
predicted interaction network belongs to the revised manuscript; it is **not**
Figure 2 of the linked v1 preprint, which depicts the original STRING network.
The website caption intentionally describes the supplied network without assigning
it a figure number from that earlier version.

The unrelated generic embedding graphic previously shown for “From Prediction to
Action…” was removed. That entry remains text-only until a figure from its own
paper is selected. No publication shares a thumbnail with a different publication.
